# Dia 4 — Sistema de Vendas

Projeto desenvolvido durante a Jornada Python para praticar a criação de um sistema de vendas interativo utilizando Python.

## 🚀 Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- Plotly

## 💻 Funcionalidades

- Cadastro de vendas por data, vendedor, produto, quantidade e valor.
- Seleção de vendedores e produtos por menus interativos.
- Armazenamento dos registros no arquivo CSV.
- Exibição das vendas cadastradas em uma tabela.
- Visualização do faturamento total.
- Gráfico de vendas por vendedor e produto.
- Gráfico de distribuição do faturamento por produto.

## 📊 Dashboard

O dashboard apresenta o faturamento total e gráficos que permitem visualizar as vendas por vendedor e por produto.

## ⚙️ Como executar o projeto

1. Instale o Python.
2. Instale as dependências:

   ```bash
   pip install -r requirements.txt
   ```

3. Execute o sistema:

   ```bash
   streamlit run codigo.py
   ```

## 📁 Arquivos do projeto

- `codigo.py`: código principal do sistema.
- `requirements.txt`: bibliotecas necessárias para executar o projeto.
- `vendas.csv`: base de dados utilizada para registrar e visualizar as vendas.

## 📚 Contexto

Este projeto faz parte dos meus estudos na Jornada Python. Nele, pratiquei a manipulação de dados com Pandas, a criação de interfaces com Streamlit e a visualização de dados com Plotly.
