# Dia 1 — Automação de Cadastro de Produtos

Projeto desenvolvido durante a Jornada Python da Hashtag Treinamentos.

## Objetivo

Automatizar o cadastro de produtos em um sistema web usando Python e dados armazenados em um arquivo CSV.

## Tecnologias

- Python
- PyAutoGUI
- Pandas

## Arquivos

- `codigogit.py`: código de automação com marcadores para as credenciais.
- `produtos.csv`: base de dados utilizada no exercício.
- `pegar_posicao.py`: script auxiliar para identificar posições na tela.

## Observação

Projeto educacional. A automação depende da posição dos elementos na tela e da estrutura do formulário utilizado no curso.

## Como executar

Instale as dependências:

`pip install pyautogui pandas`

Execute o script a partir da pasta principal do projeto, ajustando o caminho do CSV conforme necessário. Configure suas próprias credenciais localmente antes de executar a automação.
